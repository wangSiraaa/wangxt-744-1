## 1. 产品概述

露营营位天气看板是为露营地管理者和游客设计的实时天气风险可视化平台。营地主理人可维护营位信息与天气标签，游客可直观查看各营位风险等级、保存预约草稿，在风险升高时收到撤离提示，离线时仍可查看最近天气快照。

- 解决问题：营地天气风险信息不对称、强风营位误预约、离线无数据可用
- 目标用户：露营地主理人（管理端）、游客（查看+预约端）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 营地主理人 | 直接使用管理面板 | 维护营位、配置天气标签、查看全局风险 |
| 游客 | 浏览营位地图 | 查看风险等级、筛选天气、保存预约草稿、接收撤离提示 |

### 2.2 功能模块

1. **营位地图页面**：可视化营位布局、天气状态色标、风险等级标注
2. **天气筛选与风险提示页面**：按天气标签筛选营位、显示撤离提示
3. **预约草稿页面**：选择营位、填写预约信息、保存草稿、恢复草稿

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 营位地图 | 营位网格 | 展示营位位置、名称、天气图标、风险等级色标；点击营位弹出详情 |
| 营位地图 | 天气筛选栏 | 按天气标签（晴/雨/强风/雷暴等）筛选营位 |
| 营位地图 | 撤离提示横幅 | 风险等级升高时顶部显示撤离警告 |
| 营位地图 | 离线状态指示 | 离线时显示快照时间戳和离线标识 |
| 预约草稿 | 营位选择 | 在地图中点击营位进入预约面板 |
| 预约草稿 | 预约表单 | 填写姓名、日期、人数；强风营位预约按钮禁用 |
| 预约草稿 | 草稿列表 | 查看/恢复/删除已保存的预约草稿 |
| 管理面板 | 营位管理 | 新增/编辑/删除营位，设置坐标和类型 |
| 管理面板 | 天气标签管理 | 新增/编辑天气标签，关联风险等级和颜色 |

## 3. 核心流程

**游客查看营位并预约流程**：游客进入营位地图 → 浏览各营位天气与风险 → 使用天气筛选缩小范围 → 点击营位查看详情 → 若非强风则可预约 → 填写预约信息 → 保存草稿 → 下次访问可恢复草稿

**风险升级撤离流程**：系统检测到天气风险等级升高 → 顶部显示撤离提示横幅 → 强风营位标记为不可预约 → 游客收到视觉警告

**离线快照流程**：在线时自动缓存天气数据 → 网络断开 → 显示离线标识和快照时间 → 使用缓存数据渲染地图

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：森林绿 `#2D5016` + 警示橙 `#E67E22` + 紧急红 `#C0392B`
- 辅助色：天空蓝 `#5DADE2`、沙棕 `#D4A76A`
- 按钮风格：圆角矩形，带微阴影，hover 时轻微上浮
- 字体：标题使用 `Playfair Display`，正文使用 `DM Sans`
- 布局：左侧营位地图为主区域，右侧天气筛选与营位详情面板
- 图标：lucide-react 图标库
- 天气视觉：营位按风险等级着色（绿/黄/橙/红），天气图标动画

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 营位地图 | 营位网格 | CSS Grid 布局，每个营位卡片带天气图标、风险色条、名称标签 |
| 营位地图 | 天气筛选栏 | 横排标签按钮组，选中态高亮，支持多选 |
| 营位地图 | 撤离提示横幅 | 顶部红色横幅，闪烁动画，含撤离图标和文字 |
| 营位地图 | 离线指示 | 右上角离线徽章，显示快照时间 |
| 预约草稿 | 预约面板 | 侧滑面板，表单输入框，禁用态预约按钮变灰并带提示 |
| 预约草稿 | 草稿列表 | 底部卡片列表，支持恢复和删除 |
| 管理面板 | 营位编辑 | 弹窗表单，坐标输入，类型下拉 |
| 管理面板 | 天气标签编辑 | 行内编辑表格，颜色选择器 |

### 4.3 响应式设计

- 桌面优先设计：地图区域占主区域 70%，侧面板 30%
- 平板适配：侧面板改为底部抽屉
- 移动端适配：地图全宽，筛选栏水平滚动，面板全屏弹窗

### 4.4 动效设计

- 营位卡片：hover 时轻微缩放 + 阴影加深
- 撤离提示：红色横幅滑入 + 文字脉冲闪烁
- 风险等级变化：营位色条渐变过渡
- 筛选切换：营位卡片淡入淡出
- 离线提示：徽章抖动提醒
